# ДомоПлан Обмер

Голосовой обмер квартиры или дома для ДомоПлана: помещения, стены, окна, двери, откосы и работы по помещениям. Работает на iPhone (Safari) и ПК (Chrome/Edge), после первого открытия без интернета.

- `site/` — то, что публикуется на GitHub Pages (`index.html` собирается из `src/` командой `python3 build.py`).
- `src/` — исходники: `core.js` (разбор фраз, геометрия, объёмы), `works.js` + `catalog.js` (каталог работ сметы ДомоПлана), `app.js` (интерфейс, голос), `page.html` (разметка).
- Модель речи Vosk (vosk-model-small-ru-0.22, Apache 2.0) скачивается при публикации, библиотека `site/vendor/vosk.js` — vosk-browser 0.0.8 (Apache 2.0).
- Формат файла обмера: см. `Формат файла обмера.md`.
