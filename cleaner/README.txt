МАСТЕР ОЧИСТКИ И УСКОРЕНИЯ WINDOWS 10/11
=========================================

КАК ЗАПУСТИТЬ
1. Распакуйте архив в любую папку (или на флешку). Запускать прямо из архива нельзя.
2. Дважды щёлкните START.bat.
3. Windows спросит «Разрешить этому приложению вносить изменения?» — нажмите «Да».
   Если появится синее окно «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

ЧТО ДЕЛАЕТ МАСТЕР (по шагам, слева в окне)
1. Начало — сведения о компьютере: память, диск (SSD/HDD, износ), свободное место.
2. Безопасная очистка — точка восстановления, Корзина, временные файлы, кэш обновлений,
   «Очистка диска» Windows с системными файлами, DISM. Показывает «было / стало».
3. Крупные файлы — большие файлы и старые установщики в вашей папке. Удаляет только отмеченное, по умолчанию в Корзину.
4. WizTree, Bulk Crap Uninstaller, DriverStore Explorer — запуск с подсказками по-русски.
   Если программы нет в папке Tools, мастер скачает портативную версию с официального сайта.
5. Автозагрузка и скорость — отключение лишнего в автозагрузке (обратимо), план питания,
   эффекты, гибернация, TRIM для SSD, проверка системных файлов.
6. Шпаргалка команд — chrome://..., edge://..., ms-settings:..., с кнопками «Копировать» и «Открыть».
7. Итог — что сделано, сколько места освобождено, что ещё стоит сделать.

ЦВЕТА
  Зелёный — безопасно.  Жёлтый — на ваше решение.  Красный — не трогать.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
  Win+R → rstrui → Enter → выберите точку «Мастер очистки» → откат. Личные файлы не трогаются.
  Отключённое в автозагрузке включается обратно в шаге 5 или в Диспетчере задач.

ЖУРНАЛ
  Все действия записываются в папку Logs (журнал, отчёт, копии удалённых записей автозагрузки).
