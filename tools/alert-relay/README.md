# Быстрые тревоги для часов на iPad

Старый iPad сам не может открыть сайты тревог, поэтому раньше тревога приходила через GitHub
с опозданием 10–15 минут. Ноутбук дома спрашивает siren.pp.ua каждые 10 секунд и передаёт ответ
iPad-у по домашнему Wi-Fi. iPad спрашивает ноутбук тоже каждые 10 секунд. Итого тревога
появляется на часах примерно через 10–30 секунд после того, как её объявили на сайте.

Если ноутбук выключен или не отвечает, часы сами возвращаются к старому способу (через GitHub).

## Установка на ноутбук (Linux Mint), один раз

1. Ноутбук подключён к тому же Wi-Fi, что и iPad.
2. Откройте «Терминал» (меню → Терминал) и вставьте одну строку:

   ```
   curl -fsSL https://raw.githubusercontent.com/dimasbors-design/obmer/main/tools/alert-relay/install.sh | sudo bash
   ```

   Попросит пароль от ноутбука (при вводе символы не видны, это нормально).
3. В конце будет написано «ГОТОВО» и адрес для iPad, например `http://probook.local:8088`.
4. Перезагрузите ноутбук один раз, чтобы он перестал засыпать с закрытой крышкой.

## Подключение iPad, один раз

1. На iPad откройте https://dimasbors-design.github.io/obmer/clock/relaytest.html
2. Впишите адрес из шага 3 и нажмите «Проверить». Если «РАБОТАЕТ» — нажмите ссылку
   «Открыть часы с этим ноутбуком». Адрес запомнится.
3. Если с именем `.local` не работает, попробуйте запасной адрес с цифрами (тоже был в шаге 3).

## Проверка учебной тревогой

На ноутбуке откройте в браузере http://localhost:8088/ и нажмите «Учебная тревога».
Через 10–20 секунд на iPad появится полоса ТРЕВОГА (на 3 минуты, можно остановить там же).

## Полезное

- Состояние службы: `systemctl status alert-relay`
- Журнал: `journalctl -u alert-relay -f`
- Отключить быстрые тревоги на iPad: открыть часы со ссылкой `.../clock/?relay=off`
