# Формат файла обмера (`*.obmer.json`), версия 1

Файл сохраняет «ДомоПлан Обмер» (меню → «Сохранить файл обмера»). Все размеры в метрах.

```json
{
  "format": "domoplan-obmer", "version": 1, "units": "m",
  "name": "Объект 24.11.2026", "created": "2026-11-24T10:00:00.000Z",
  "rooms": [{
    "id": "r…", "number": 1, "name": "Кухня", "height": 2.7,
    "walls": [
      {"length": 3.4, "turn": 90,
       "openings": [{"type": "window", "offset": 0.4, "width": 1.4, "height": 1.5, "sill": 0.85, "reveal": 0.2}],
       "items": [{"type": "radiator", "offset": 0.6, "width": 1.0}]},
      {"length": 2.8, "turn": 90, "openings": [], "items": []}
    ],
    "diagonals": [{"from": 1, "to": 3, "length": 4.4}],
    "notes": ["трещина на потолке"],
    "works": [
      {"said": "штукатурка стен по маякам", "id": "w_beacons", "name": "Штукатурка стен по маякам (до 20 мм)", "base": "walls", "unit": "м²", "alts": ["wx_114"]},
      {"said": "розетки", "id": "e_socket", "name": "Установка подрозетника и розетки/выключателя", "base": "manual", "unit": "точка", "qty": 6}
    ]
  }]
}
```

## Геометрия
- Стены перечислены по часовой стрелке (вид сверху) по внутренним поверхностям («в свету»). Стена 1 начинается в левом углу, если стоять в дверях лицом в комнату.
- Построение: угол 1 в (0,0), стена 1 идёт по +X. Экранные координаты, Y вниз.
- `turn` — поворот направления в конце стены, в градусах: `90` — обычный (выпуклый) угол, `-90` — внутренний (Г-образные комнаты), другое значение = 180 − внутренний угол комнаты.
- `diagonals` (необязательно): диагональ из угла 1 в угол 3. Для комнат из 4 стен по ней строится точная форма двумя треугольниками.

## Проёмы и предметы
- `offset` — от начала стены (левый угол, если смотреть на стену изнутри) до ближнего края проёма.
- `type` у `openings`: `window`, `door`, `opening` (проём без двери), `niche` (ниша, `depth` в стену), `box` (короб или выступ, `depth` в комнату).
- `sill` — высота низа окна от пола; `reveal` — глубина откоса; `to` — куда ведёт дверь (текст).
- `type` у `items`: `radiator`, `riser`, `panel`, `socket`, `switch`, `vent`, `pipe`, `meter`, `boiler`; `offset`/`width`/`height` при наличии.
- Любое поле может отсутствовать, если его не продиктовали.

## Что считает сам Обмер (для сверки)
Площадь пола (по контуру), периметр, площадь стен = периметр × высота − проёмы (окна, двери, проёмы) + боковины ниш и коробов, откосы = (2 × высота + ширина) × глубина откоса для каждого проёма с откосом, плинтус = периметр − ширины дверей и проёмов, подоконники = ширины окон, объём = пол × высота.

## Работы по помещению (`works`)
- Продиктованная работа («работа покраска потолка») сопоставляется с каталогом работ сметы ДомоПлана (каталог взят из сборки от 14.11.2026, 760 работ). `id`, `base`, `unit`, `name` — как в каталоге сметы.
- `qty` есть, только если количество продиктовано или введено вручную. Иначе количество берётся из замеров помещения по `base`: `walls` — стены без проёмов, `floor` — пол, `ceil` — потолок, `plinth` — плинтус, `slopeL` — откосы в п.м, `slopeA` — откосы в м², `per` — периметр, `door` — число дверей, `win` — число окон.
- Если работа не нашлась в каталоге, `id` нет, `name` — продиктованный текст, `base` = `manual`.
- `alts` — другие подходящие работы из каталога (для выбора на ПК).
